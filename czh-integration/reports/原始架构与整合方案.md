# 原始架构与正式整合方案

原始 `ocr-menu-demo/` 是前端演示原型；组员 1 的 OCR 与解析、组员 2 的 HTTP/SQLite 后端、组员 3 的页面已部分连接，但旧前端混用 localStorage、IndexedDB 和后端数据，离线或保存失败可能导致数据认知不一致；图片校验依赖扩展名回退。原始目录以当前 master 为准保留。

正式版本在 `complete-project/` 中分为 `ocr/`、`backend/`、`web/`、`tests/`。Demo 的校验及导出流程融入唯一正式界面，移除完整项目中的重复 Demo 与浏览器 XLSX 生成逻辑；原始 Demo 仍位于仓库根目录。正式界面通过 API 上传、读取、编辑、删除和导出，SQLite 是唯一菜品数据源，OCR 引擎和解析器作为后端模块复用。新增 `has_image`，并将上传图片文件名存为相对数据目录路径。

Windows 中文 OCR、统一入口、数据持久化和错误反馈已通过本机验证；跨系统 OCR、超过 2000 条记录的处理、用户认证及学校表格同步仍待补充。具体测试见 `test-report.md`。
