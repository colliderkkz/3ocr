# 餐饮菜单识别与管理 Demo

这是根据《基于OCR的餐饮菜单识别与管理系统PRD.md》制作的无构建工具前端 Demo。

## 运行

在本目录执行：

```powershell
python -m http.server 8765
```

浏览器打开 `http://127.0.0.1:8765/`。也可直接打开 `index.html`，但使用本地服务器能让图片持久化更稳定。

## 演示流程

1. 打开“校验工作台”，内置样例已有两张菜单图和模拟 OCR 记录。
2. 点击记录或原图上的示意框定位；双击记录可修改菜名、价格、分类和类型，保存后计入校验进度。
3. 切换到第二张图，处理蓝色疑似重复项，可合并并保留来源图片引用，也可标为非重复。
4. 处理待校验和异常项后点击“完成校验”，再从工作台或菜品库导出 `.xlsx`。
5. 在“上传批次”中新增门店并上传 JPG/PNG（最多 30 张）。上传后可粘贴外部 OCR 工具识别出的逐行文本，点击“解析当前图片文本”；也可手工新增记录。

记录和门店保存在浏览器 `localStorage`，上传图片保存在 `IndexedDB`。刷新页面后可继续校验。同一浏览器来源使用同一份本地数据。

## Demo 边界

上传图片后不会自动识别：当前环境未安装 PaddleOCR，页面明确标注为纯前端流程演示。内置样例的识别结果与框是模拟数据；用户图片不会套用样例记录。文本解析支持常见分类标题、行尾价格、独立价格行和缺失项提示，但真实 OCR 准确率、倾斜校正和对比度增强不在此 Demo 中验证。
